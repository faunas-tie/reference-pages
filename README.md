# reference-pages

Simple reference pages, easy to view on a phone. Each page has its own folder.

## Pages

- [Skincare routine](https://faunas-tie.github.io/reference-pages/skincare/)

## Rules

This repo and its pages are public, so keep them free of personal details:
no names, addresses, prices, retailers or travel dates.

Each page is one self-contained `index.html`, with its images embedded, so it
needs no build step. Commit message format: `ref: <short description>`.
